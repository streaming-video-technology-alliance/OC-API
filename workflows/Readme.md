## To generate workflows images

Select your workflow file (like service1.txt) to view it in browser  
Click on "raw" button to get a link in browser address bar, for example:

https://raw.githubusercontent.com/streaming-video-alliance/OC-API/try-to-generate-server/workflows/serviceconf4.txt?token=AMOK4S5RTV5KEWGCZ5WAVXLBE5S6G  

Then go to :  

http://www.plantuml.com/plantuml/proxy?cache=no&src=  

and insert this link after src:  

http://www.plantuml.com/plantuml/proxy?cache=no&src=https://raw.githubusercontent.com/streaming-video-alliance/OC-API/try-to-generate-server/workflows/serviceconf1.txt?token=AMOK4S2U2DSZBHNWXAY2ZW3BE5SIO

Save image and update it on github.
